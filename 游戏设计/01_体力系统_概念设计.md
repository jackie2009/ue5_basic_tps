# 体力系统：概念设计（Stamina）

> 文档定位：单机剧情 / 刷宝动作 RPG 的长期设计备忘；只记录体验目标、系统规则和待定事项，不涉及代码、蓝图或引擎实现。
>
> 版本：v0.1 · 2026-11-25  
> 状态：**核心方向已明确；阈值、数值、少量边界规则待实际体验验证**  
> 关联文档：[02_怒气系统_概念设计.md](02_怒气系统_概念设计.md)

## 一、系统目标

- **体力代表身体状态**：连续攻击、闪避、跳跃、防御会让角色疲劳；停止高消耗行为，角色逐渐恢复。
- **用体力代替普遍的技能 CD**：普通攻击、重攻击与常规剑术的使用频率，由体力、动作时长、动作风险和战斗时机决定，不靠固定秒数倒计时。
- **让资源管理具有身体代入感**：玩家能直觉理解“累了打不动”“缓一口气继续战斗”。
- **适合刷宝的持续战斗**：可承受犯错，但避免频繁停下来等待；装备成长能够显著改变战斗耐力与节奏。
- **与怒气分工**：体力是短周期、自然恢复的行动能力；怒气是通过有效战斗累积、用于爆发和特殊交换的资源。

## 二、核心定义：四段体力状态

体力条按状态划分为四段，状态既决定角色的基础行动能力，也为装备和药水创造设计空间。

| 区域 | 身体含义 | 行动能力与收益 | 设计定位 |
|---|---|---|---|
| **无力区** | 严重疲劳，难以继续进攻 | **不能攻击**；仍可普通移动、尝试举盾。跳跃、闪避等高消耗行为不开放 | 短暂的危险状态，不应成为常态 |
| **疲劳区** | 可以作战，但发挥受影响 | 能攻击、移动、跳跃、闪避、举盾；**攻击收益约为正常的七成**（具体是伤害、效率或其他收益，尚待定） | 允许挣扎、撤退、反击，而不是完全停摆 |
| **普通区** | 正常战斗状态 | 允许完整的基础操作及常规技能，**按 100% 正常收益**结算 | 应当覆盖大部分普通战斗时间 |
| **活力区** | 超出通常身体状态的强化 | 在普通区全部能力基础上，获得额外奖励，例如更高攻击力 | 由药水、增益或特殊装备额外激活，不作为日常常驻状态 |

### 四段区间的关系

- **自然恢复的终点是普通体力上限**，不能单靠站立、移动就自然进入活力区。
- **活力区是额外体力 / 强化区**：药水或特定增益可让当前体力暂时超过常规上限，进入活力区；攻击消耗后可能退出活力区。
- **普通区必须有完整的基础战斗体验**，不能让玩家只有喝药才能正常战斗。
- **疲劳惩罚与活力奖励应当一眼可懂**，而不是堆叠很多隐藏例外。

> 数值示例（**仅用于讨论，未定稿**）：体力自然上限为 100；0–15 无力，15–35 疲劳，35–100 普通，药水临时突破至 125 为活力。活力攻击奖励示例 +15%。这些数字不代表最终配置。

## 三、行为与体力的关系

### 消耗体力的行为

- 普通攻击：低至中等消耗，保证连续攻击的基础流畅度。
- 重攻击与强力剑术：更高消耗，结合前摇、后摇和受击风险决定其价值。
- 闪避、跳跃：消耗体力，迫使玩家在进攻和保命之间权衡。
- 格挡承受攻击：可消耗体力；强攻击应带来明显压力。
- 同一技能不应只因“CD 转完”才可再次使用；资源和动作条件才是限制。

### 恢复体力的行为

- **正常移动与待机可以恢复体力**。
- **攻击、跳跃、闪避期间不恢复体力**。
- **持续举盾期间不恢复，或恢复极慢**；不能让玩家一边无限防御一边安全充满体力。
- 体力应在数秒尺度形成“进攻 → 调整站位 → 恢复 → 再进攻”的节奏。
- 恢复延迟与恢复速度可以调校，但不应把“等待”变成刷宝游戏的主体验。

### 盾牌与无力区的边界（推荐验证）

允许无力时举盾，符合“仍可勉强防身”的直觉；但**举盾不等于必然能够成功挡下攻击**。可采用“承受攻击消耗体力，无法支付则破防”的规则，避免体力归零后无限举盾。这条规则尚待实战验证。

## 四、完整战斗节奏

1. 玩家以普通区体力进入战斗，拥有完整操作空间。
2. 攻击、闪避、防御逐渐消耗体力；连续高强度动作使角色接近疲劳区。
3. 进入疲劳区仍可作战，但需要谨慎决定是否继续攻击，或拉开距离恢复。
4. 进入无力区属于明显失误或高风险选择，要求短暂撤退，而不是长时间丧失参与权。
5. 药水或特殊增益可临时进入活力区，形成主动制造的爆发窗口。

**重要原则**：体力系统要表达“身体负担”，但不能导致“越被压制 → 伤害越低 → 敌人更难杀 → 永远无法恢复”的恶性循环。尤其多怪战斗必须确保普通移动能提供合理的回气机会。

## 五、与怒气的关系

- 体力主要**限制持续行动能力**；怒气主要**控制爆发技能与关键抉择**。
- 有些技能允许 **体力换怒气**：以高体力消耗、有效命中和动作风险换取战斗势能。
- 有些技能允许 **怒气换体力**：牺牲原本可以用于爆发的怒气，换取续航或脱离疲劳。
- 两者不能是无损、可在空地反复使用的等价货币；转换必须有机会成本。
- 详见《怒气系统：概念设计》。

## 六、刷宝与装备构筑方向

装备应改变“如何使用体力”，而不只是简单提高体力上限：

| 构筑方向 | 示例效果（非最终词缀） |
|---|---|
| 耐力型 | 降低普通攻击体力消耗、加快移动恢复 |
| 重击型 | 重攻击消耗更多体力，但获得更高攻击收益或怒气收益 |
| 盾反型 | 成功格挡体力损耗较低、完美格挡恢复少量体力 |
| 疲劳型 | 疲劳区惩罚减轻，或在疲劳区获得额外战斗收益 |
| 活力型 | 延长活力区的有效作用，强化活力区的奖励 |
| 资源交换型 | 通过怒气技能快速回体，或者以体力换取更高怒气效率 |

**约束**：特殊装备可以改变区域收益，但不应使“无力区完全无法行动”的体验频繁出现，也不应轻易破坏资源交换的总成本。

## 七、已明确与待决定

### 已明确的设计方向

- 不使用传统技能 CD 作为普遍限制方式。
- 战斗资源只有**体力和怒气**两种核心概念。
- 体力采用**无力 / 疲劳 / 普通 / 活力**四段状态。
- 无力区不能攻击；疲劳区仍能攻击但收益降低；普通区是默认完整战斗状态；活力区是额外奖励。
- 攻击及高消耗行为花费体力；普通移动和待机恢复体力；举盾时恢复为零或极低。
- 活力区由药水 / 增益类效果额外开启，非自然常驻。

### 后续测试时再决定

- 各区域准确阈值、体力上限、恢复速度、恢复延迟。
- 疲劳区“七成攻击收益”到底采用伤害倍率、体力效率还是其他表达方式；**目前优先保留用户提出的七成收益概念**。
- 跳跃、闪避、格挡的消耗；无力区举盾后的破防规则。
- 活力区提升的具体属性，以及活力体力的消耗/衰减方式。
- 不同武器、装备词缀和大规模怪群下的节奏平衡。

---

**一句话设计原则**：体力负责让角色像一个有身体极限的人；普通状态足够好玩，疲劳状态有代价，活力状态有奖励。
