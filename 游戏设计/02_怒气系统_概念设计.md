# 怒气系统：概念设计（Rage）

> 文档定位：单机剧情 / 刷宝动作 RPG 的长期设计备忘；只记录体验目标、资源关系、技能构筑方向和开放问题，不涉及代码、蓝图或引擎实现。
>
> 版本：v0.1 · 2026-11-25  
> 状态：**概念方向明确；积累、兑换、脱战保留等机制尚处于方案阶段**  
> 关联文档：[01_体力系统_概念设计.md](01_体力系统_概念设计.md)

## 一、为什么需要怒气

游戏决定**全面放弃传统技能 CD 的概念**，只保留体力与怒气两个核心战斗资源。

- **体力**是能快速恢复的身体行动能力，负责常规攻击、防御、闪避、跳跃等短循环。
- **怒气**是战斗行为积累起来的爆发潜力，负责强力招式、临场反击与资源交换等中循环。
- 怒气不是“另一条体力”：**不能主要靠站着等待恢复，也不应只是第二种蓝条**。
- 玩家应当在“现在爆发”与“将怒气留作后续生存或更大收益”之间做出选择。

## 二、怒气的获取原则（设计候选）

**方向：通过有效战斗获取，而不是靠时间自动增长。**

| 行为 | 候选收益 | 设计用意 |
|---|---|---|
| 普通攻击有效命中 | 少量怒气 | 稳定、可理解的基础积累 |
| 重攻击有效命中 | 较高怒气 | 用更多体力和动作风险换取怒气 |
| 完美格挡 / 精准反击 | 较高怒气 | 鼓励技术性防御，支持盾反构筑 |
| 受到攻击 | 少量或有条件获得 | 提供逆境反击感，但不能鼓励刻意挨打 |
| 击败精英 / 创造破绽 | 可选额外奖励 | 制造战斗高潮，但不能让 Boss 战完全依赖小怪供给 |

### 反刷资源原则

- **空挥、原地刷技能、离开真实战斗反复操作，不应稳定产生怒气。**
- 怒气收益可以取决于**命中质量、技能风险和动作价值**，不宜简单按每段命中等量发放，否则高攻速、多段伤害天然获得过大优势。
- 消耗怒气的技能原则上**不按普通命中规则再次大量产怒**，避免自产自销。
- 怒气应能在单独 Boss 战里靠正常攻击、防御、抓破绽持续积累。

## 三、怒气如何消耗

怒气主要有三个出口：

### 1. 爆发攻击

消耗怒气，换取比普通招式更大的伤害、范围、破防能力或特殊效果。可同时花费少量体力，保留身体动作的真实感。

### 2. 防守与续航

例如“战吼 / 振作”：牺牲一部分怒气，恢复体力，使角色脱离疲劳或重新获得行动余量。

**关键的抉择不是技能是否转好 CD，而是：这次怒气拿来杀敌，还是拿来保命？**

### 3. 特殊战斗状态

可通过装备或专属技能，将怒气转化为短暂强化、破防、反击等效果。是否采用持续型强化状态，目前不强制决定，避免系统变复杂。

## 四、体力与怒气的互换是构筑核心

资源循环的基本方向：

```text
体力（自然恢复）
  ↓  消耗体力进行真实战斗
有效命中 / 精准防御 / 创造破绽
  ↓
怒气（战斗累积）
  ├──→ 爆发输出：更快击败敌人
  └──→ 恢复体力：提升续航与安全性
```

### 三种值得保留的技能形态

| 技能类型 | 交换关系 | 玩家抉择 |
|---|---|---|
| **以体力换怒气** | 高耗体力的攻击，命中后快速积累怒气 | 现在冒险进攻，为后续爆发铺垫 |
| **以怒气换体力** | 消耗怒气进行战吼、振作或恢复 | 放弃部分伤害潜力，挽回体力局面 |
| **体力与怒气共同消耗** | 强力剑术同时消耗两者 | 必须兼顾身体状态与积攒成果 |

**不要求两种资源能够直接无条件兑换**。更优先让兑换附着在有战斗意义的动作上，避免站在安全区反复转换就能变强。

### 防止无限循环的规则

1. 体力 → 怒气的高收益路径，通常需要**有效命中、成功防御或承担实战风险**。
2. 怒气 → 体力必须有**转换损失和机会成本**，不能与自然恢复叠加形成无代价循环。
3. 消耗怒气的招式应限制自身返还怒气的能力；特殊例外只用于谨慎设计的稀有装备。
4. 即使两种资源的数值互相改变，也不能保证每个循环都能净赚体力与怒气。

> 示例（**非定稿数值**）：重攻击消耗较多体力，命中获得怒气；“战吼”消耗 40 怒气恢复 30 体力；强力技消耗 30 体力 + 40 怒气。这些数字只帮助理解交换关系。

## 五、与四段体力状态的联动

详见《体力系统：概念设计》。四段是**无力、疲劳、普通、活力**。

- **无力区**：无法普通攻击；可能仍可通过成功防御获得少量怒气。怒气救急技能是否允许无力时使用，需要统一规则。
- **疲劳区**：可以考虑让有效攻击 / 完美格挡的怒气收益略高，表达“身体疲惫，但斗志高涨”。这是**值得测试的方案，不是已定规则**。
- **普通区**：标准怒气收益，战斗循环最稳定。
- **活力区**：主要通过额外攻击奖励体现价值，不必让怒气获取也显著加速，以免奖励叠加过高。

### 有戏剧性的战斗情境

角色体力很低、怒气很高时，玩家有两条明确的选择：

- 消耗怒气恢复体力，重返稳定状态；
- 保留危险身体状态，利用已有怒气抓住时机打出决定性攻击。

这比“等待技能 CD 好了再用”更符合单机动作 RPG 的代入感。

## 六、怒气在一场战斗内外如何变化（未决定）

这是**当前最重要的开放问题**，暂不当作既定规则。

| 方案 | 规则 | 代价与效果 |
|---|---|---|
| A：完全保留 | 脱战后保留全部怒气 | 容易在普通怪处攒满，再进入 Boss 战爆发 |
| B：逐渐归零 | 脱战后逐渐衰减 | 强化连续战斗，但每场都要从头积累 |
| **C：部分保留（当前建议）** | 脱战后高于某个保底值的怒气逐渐下降，保留一部分 | 兼顾战斗节奏与积累感 |

目前倾向先测试 C，例如怒气能积累至 100、脱战逐渐回落至 50，**但数值和方案均未最终确定**。

## 七、对刷宝系统的价值

装备不只提高怒气上限，更应该改变“获得与花费怒气的方式”。

| 构筑方向 | 示例效果（非最终词缀） |
|---|---|
| 狂战士 | 疲劳状态下命中额外获得怒气 |
| 盾反流 | 完美格挡额外获得怒气，降低格挡体力代价 |
| 重武器流 | 重击花费更多体力，却获得更多怒气或更强破防 |
| 续航流 | 消耗怒气的技能恢复部分体力 |
| 爆发流 | 消耗怒气时获得更大范围、更高伤害或特殊附加效果 |
| 高风险流 | 低体力时强化怒气技能，但必须承受无力区风险 |

**平衡边界**：不要出现“不用打怪也能永远刷满怒气”的通用装备组合；对特殊强力装备，可以允许改变规则，但必须有可感知代价。

## 八、已明确与待决定

### 已明确的设计方向

- 核心战斗资源只有**体力与怒气**，不以传统 CD 为主。
- 怒气用于强力攻击，以及与体力之间的战斗性资源交换。
- 体力和怒气不能是完全等价、无损可循环的两种货币。
- 怒气系统要服务于单机动作感和装备构筑，而不是构造复杂的 MMO 技能循环。

### 待测试 / 待决定

- 怒气主要来自哪些行为，以及各行为的相对权重。
- 普通攻击、重击、多段攻击、完美格挡、受击的怒气计算逻辑。
- 不同技能需要“只花怒气”还是“同时花体力和怒气”。
- 怒气与疲劳区的联动是否成立，是否鼓励低体力高风险玩法。
- 无力区能否使用“消耗怒气恢复体力”的自救技能。
- 怒气的上限、消耗量和积累节奏。
- 脱战后怒气**保留、清空还是部分衰减**：目前仅倾向测试部分保留。
- 如何限制极端刷怒与无限交换流派，同时保留稀有装备的突破感。

---

**一句话设计原则**：体力决定现在还能做多少动作，怒气决定积攒的战斗势能如何兑现；两者互换产生策略，但不能无代价循环。
